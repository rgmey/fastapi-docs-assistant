# FastAPI Docs Assistant

A question-answering assistant over the FastAPI documentation, built with a focus on
measurable quality: every design choice is backed by evaluation results.

## Problem
Developers learning FastAPI often have specific questions ("how do I add a dependency
to every route in a router?") that require reading several doc pages. This assistant
answers them with citations to the exact sections it used.

## What counts as a good answer
- Correct according to the official docs
- Cites the doc sections it relied on
- Says "I don't know" rather than guessing when the docs don't cover it
